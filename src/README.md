CAD viewer source: cad-viewer.js. Bundled with esbuild 0.28.2 and three 0.187.0 (see original installed version when rebuilding). Runtime dynamically imports dist/cad-viewer.js only when opening a CAD model. Catalog snapshot and upstream licenses live in dist/assets/cad and dist/licenses. Wokwi SVG assets are static flattened front illustrations, not full 3D geometry. The existing circuit solver is separate from the CAD gallery.

Visual Studio update: 48 static Wokwi front illustrations are used across the reference catalog. These are front drawings, with approximate thickness in the circuit scene; they are not full mechanical models. CAD has 6,189 distinct upstream VRML paths pinned to commit b8b3cfdfad88ba66f21002b3de51dc6f7d55ba5a. Individual models are fetched on demand and cached with a 16-file limit. The catalog is paged at 30 entries; it does not add electrical simulation support for those models.

Verification: all SVGs passed XML parsing; six representative CAD files passed geometry parsing; a resistor was rendered through the software 3D fallback in the browser. The application was tested inside a 390px iframe (375px content viewport after scrollbar), including search, filters, navigation and a live GPIO square wave. Search, scope transition capture, freeze and bounded ring buffer checks passed. Scope collects ideal solver values and GPIO transitions; PWM is represented as an average.
