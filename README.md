# VoltLab — מעבדת אלקטרוניקה אינטראקטיבית

סביבת לימוד ובנייה בעברית, עם משטח עבודה, חיבור רכיבים, סימולציה לימודית, עורך קוד, מדידות ומסלול תרגול.

**האתר שפורסם:** https://voltlab-electronics-studio.shrewdostrich16.chatgpt.site — הכניסה לאתר הפרטי באמצעות חשבון ChatGPT של הבעלים.

המאגר כולל את הגרסה האחרונה שפורסמה, את קוד המקור, נכסי התצוגה, בדיקות ותיעוד. קובצי הפעלה מוכנים נמצאים ב־`dist/` ואינם דורשים תהליך בנייה.

## תרומה לפרויקט

יש לכם תיקון, רכיב, שיעור או רעיון? אפשר לפתוח [Issue](https://github.com/acresking/voltlab/issues) ולהגיש שינויים דרך Pull Request. ראו את [מדריך התרומה](CONTRIBUTING.md).

## הפעלה מקומית

דרושים Python 3 ודפדפן מודרני. מתוך תיקיית המאגר:

```sh
python3 -m http.server 4173 --directory dist
```

ב־Windows אפשר להשתמש ב־`py -3` במקום `python3`. פתחו בדפדפן http://localhost:4173 . יש להפעיל דרך שרת HTTP; פתיחה כ־`file://` אינה מתאימה לטעינת המודולים והקטלוג.

## מה כלול

- ממשק בעברית ופריסה מותאמת לטלפון ולמחשב.
- 102 פריטי מעבדה/למידה, 48 איורי חזית מפורטים וקטלוג נפרד של 6,189 מודלי CAD.
- בנייה וחיווט, מבטי מצלמה, חיפוש, סינון, שכפול והיסטוריית פעולות.
- סימולציית לולאת DC טורית אידאלית ומודלי GPIO וקלט לימודיים.
- מפרש Arduino מוגבל: משתנים, חישובים, `if/else`, פקודות GPIO, `map`, `constrain` ו־Serial.
- אוסצילוסקופ לימודי עם דגימות מתח/זרם, רישום שינויי GPIO, הקפאה וייצוא CSV.
- 16 שיעורים מקוריים בעברית, עם הסברים, משימות, שאלות ושמירת התקדמות.
- ייצוא JSON עם קוד ושם פרויקט, רשימת רכיבים, רשימת חיבורים וסכמה לוגית ב־SVG.

## מגבלות חשובות

זו אינה אמולציה מלאה של Arduino, ESP32 או Raspberry Pi. אין קומפיילר C++ מלא, הרצת מערכת הפעלה או Python/Java, סימולציית פרוטוקולים מלאה, מנוע רובוטיקה או עורך CAD למכלולים.

איורי החזית אינם מודלים מכניים מלאים. קטלוג ה־CAD מיועד לצפייה בגאומטריה; הוספת פריט לקטלוג אינה מבטיחה סימולציה חשמלית שלו. ערכי PWM מוצגים כממוצע, ללא תופעות מעבר אנלוגיות.

מפת יכולות מלאה: [src/FEATURES.md](src/FEATURES.md).

## מבנה המאגר

| נתיב | תפקיד |
| --- | --- |
| `dist/index.html`, `dist/style.css` | דף הכניסה והעיצוב |
| `dist/app.js` | משטח העבודה והמודל החשמלי הבסיסי |
| `dist/studio.js` | לוחות, חיישנים, קוד ושמירה מקומית |
| `dist/visual-studio.js` | איורים מפורטים, קטלוג CAD ואוסצילוסקופ |
| `dist/code-engine.js` | מפרש הקוד הלימודי |
| `dist/workbench.js` | מצבי עבודה, היסטוריה, בדיקות וייצוא |
| `dist/academy.js` | מסלול הלמידה בעברית |
| `dist/cad-viewer.js` | חבילת מציג CAD מוכנה להפעלה |
| `src/cad-viewer.js` | מקור מציג CAD לפני אריזה |
| `dist/assets/` | איורים ואינדקס מודלי CAD |
| `dist/licenses/` | רישיונות וקרדיטים של ספריות ונכסים חיצוניים |
| `tests/` | בדיקות למפרש הלימודי |
| `.openai/hosting.json` | מזהה האתר הקיים והגדרת ההגשה שלו |

פרויקטים והתקדמות משתמשים נשמרים בדפדפן, ואינם חלק מהמאגר. ניתן להעביר פרויקט באמצעות ייצוא וייבוא JSON.

## בדיקות

דרוש Node.js 20 ומעלה:

```sh
npm test
```

אין צורך להתקין חבילות כדי להפעיל את הבדיקה הזאת.

## בנייה מחדש של מציג CAD

רק אם משנים את `src/cad-viewer.js`:

```sh
npm install
npm run build:cad
```

הגרסאות הישירות מקובעות ב־`package.json`. יתר האתר הוא HTML/JavaScript סטטי ואינו זקוק לבנייה. לשינוי פריסה סטטית יש להגיש את `dist/` כתיקיית האתר.
