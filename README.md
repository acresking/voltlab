# VoltLab — מעבדת אלקטרוניקה, תלת־ממד, CAD ורובוטיקה אינטראקטיבית

סביבת לימוד, בנייה וסימולציה מקיפה בעברית (ועוד 20 שפות), המשלבת את חוויית הלמידה והעיצוב של **Learn Arduino** יחד עם כלי ההנדסה, ה־CAD, המכשור והרובוטיקה של **BenchTwin**.

**האתר שפורסם:** https://voltlab-electronics-studio.shrewdostrich16.chatgpt.site — הכניסה לאתר הפרטי באמצעות חשבון ChatGPT של הבעלים.

המאגר כולל את הגרסה האחרונה, קוד המקור, נכסי התצוגה, בדיקות ותיעוד. קובצי הפעלה מוכנים נמצאים ב־`dist/` ואינם דורשים תהליך בנייה.

## הפעלה מקומית

דרושים Python 3 (או כל שרת HTTP סטטי) ודפדפן מודרני. מתוך תיקיית המאגר:

```sh
python3 -m http.server 4173 --directory dist
```

ב־Windows אפשר להשתמש ב־`py -3 -m http.server 4173 --directory dist`. פתחו בדפדפן http://localhost:4173 .

## מה כלול בגרסה המורחבת

- **שתי ערכות עיצוב מלאות (Dual Theme):**
  - **BenchTwin Pro Dark:** ממשק מעבדה כהה והנדסי עם תצוגת 4 מבטים (Top / Front / Right / 3D) בסגנון Blender.
  - **Learn-Arduino Warm Parchment (`#f6eddd`):** עיצוב שרטוט בהיר וחם, עם סרגל צד אנכי, כרטיס התקדמות ושעון חי, ותוויות הסבר צפות על גבי הלוח והרכיבים.
- **תוויות הסבר צפות, סכמה חיה ובודק רכיבים אינטראקטיבי:**
  - **סכמה חשמלית צפה בזמן אמת:** מתעדכנת ומציגה זרימת זרם, מצבי `HIGH`/`LOW`, ערכי נגדים וצבעי LED תוך כדי הרצת הסימולציה.
  - **בודק רכיבים צף (Component Inspector):** בחירת צבעי LED (אדום, צהוב, ירוק, כחול, לבן), מחווני זמן הדלקה/כיבוי שמסתנכרנים ישירות עם פקודות `delay(...)` בקוד, בחירת ערכי נגדים ממועדפים וחיווי בהירות ובטיחות.
  - **חקירת 9 רכיבי לוח ה־Arduino Uno:** הסברים מפורטים על `ATmega328P`, `USB-B`, `ATmega16U2`, גביש 16MHz, שקע DC ופיני המתח והאות.
- **מנוע קוד מורחב (Arduino C++ & MicroPython/Python):**
  - תמיכה ב־`setup()`, `loop()`, משתנים, חישובים, תנאי `if / else if / else`, לולאות `for`, קדם־מעבד `#include` ו־`#define`.
  - פקודות חומרה ופרוטוקולים: `pinMode`, `digitalWrite`, `analogWrite` (PWM), `analogRead`, `digitalRead`, `tone()` / `noTone()` (הפקת צליל חי דרך WebAudio!), `pulseIn()` לחיישן מרחק HC-SR04, ספריית `Servo.h` (`attach`, `write`), תצוגת `LCD 1602` / `OLED` וקריאת חיישני `DHT22` / `BME280` / `MPU6050`.
  - **הרצת MicroPython / Python חיה** ללוחות Raspberry Pi Pico ו־Raspberry Pi (`Pin`, `LED`, `PWM`, `ADC`, `sleep`, `print`).
  - **כפתורי פרמטרים מהירים בקוד:** לחיצה על ערכי `delay`, `analogWrite` ו־`tone` לשינוי חי תוך כדי ריצה, כולל הודעות קומפילציה והעלאה במוניטור הטורי.
- **מכשור מעבדה ובטיחות (BenchTwin Lab Tools):**
  - **אוסצילוסקופ דו־ערוצי חי:** דגימת מתח וזרם, הקפאה (Freeze) וייצוא CSV.
  - **רב־מודד דיגיטלי (DMM):** מדידת מתח (V), זרם (mA), התנגדות (Ω), הספק (mW) ובדיקת רציפות.
  - **מנתח לוגי וציר זמן פינים (Logic Analyzer & Pin Timeline):** תיעוד חי של מעברי GPIO, יחסי PWM, תדרי Tone וזוויות Servo.
  - **מצב בטיחות מול מצב מציאותי (Safety Mode):** בכיבוי מצב הבטיחות, זרם יתר (>20mA) או קצר יגרמו לעשן ושריפת ה־LED בזמן אמת.
- **תכנון מארז תלת־ממדי (Enclosure CAD) וייצוא STL:**
  - יצירת מארז מותאם אוטומטית למידות המעגל שעל השולחן, בחירת עמודי ברגים (M2 עד M5), פתחי USB ואוורור, וייצוא קובץ **STL** אמיתי להדפסת תלת־ממד.
- **סימולטור רובוטיקה וזירת תחרויות (2WD Robotics Arena):**
  - ניווט אוטונומי במגרש וירטואלי עם חיישן מרחק אולטרה־סוני, הימנעות ממכשולים, איסוף יעדים וטלמטריה חיה של מנועי שמאל/ימין וסרוו.
- **מסלול למידה מלא בעברית (16 שיעורים בסגנון Learn Arduino):**
  - כל שיעור בנוי מ־5 לשוניות: **סקירה**, **פריסת פינים** (טבלת חיווט מפורטת), **דוגמה** (הסבר קוד שורה־אחר־שורה), **מפרט** (נתונים טכניים) ו**תרגול חי** עם אימות אוטומטי ושאלת הבנה.
- **ייצוא ורשימת קניות (Shopping List & BOM):**
  - ייצוא רשימת רכיבים, ברגים וספריות קוד (CSV), טבלת חיבורים (CSV), סכמה הנדסית (SVG), קובץ פרויקט (JSON) ומארז (STL).

## מבנה המאגר

| נתיב | תפקיד |
| --- | --- |
| `dist/index.html`, `dist/style.css` | דף הכניסה וערכות העיצוב (BenchTwin Dark & Learn-Arduino Parchment) |
| `dist/app.js` | משטח העבודה התלת־ממדי והמודל החשמלי הבסיסי |
| `dist/studio.js` | לוחות, חיישנים, קוד ושמירה מקומית |
| `dist/visual-studio.js` | איורים מפורטים, קטלוג 6,189 מודלי CAD ואוסצילוסקופ |
| `dist/code-engine.js` | מנוע הקוד המורחב (Arduino C++, MicroPython, Servo, Tone, Ultrasonic, LCD) |
| `dist/workbench.js` | סרגל ניווט, בודק רכיבים צף, סכמה חיה, מולטימטר, מנתח לוגי, מארז STL וזירת רובוטיקה |
| `dist/academy.js` | מסלול 16 השיעורים בעברית עם טבלאות פינים, הסברי קוד, מפרטים ותרגול |
| `dist/cad-viewer.js` | חבילת מציג CAD תלת־ממדי מוכנה להפעלה |
| `tests/` | בדיקות אוטומטיות למנוע הקוד והפרוטוקולים |
